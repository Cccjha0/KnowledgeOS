# Reading Log

## User guide

Put scattered book, article, or paper notes in the module or instance Inbox. The module proposes a sourced reading note, maintains a lightweight title index, and creates one weekly summary. Ambiguous source identity or replacement of user fields requires Review. Pausing stops weekly work; archiving retains notes, index, summaries, links, and Run history.

Out of scope: downloading books, online review lookup, recommendations, complex knowledge graphs, and cross-module writes.

## Developer notes

The module owns only its instance content roots. It returns structured plans through the Module SDK and never writes files directly.
