# Use Case Brief

- User need: turn scattered reading thoughts into reusable notes without losing provenance.
- Primary inputs: short text or Markdown Captures about books, articles, and papers.
- Primary outputs: reading notes, a title index, and weekly summaries.
- Daily journey: Capture → classify → normalize → Review ambiguity → Core executes plan.
- Explicitly out of scope: downloads, online lookup, recommendations, complex graphs, cross-module writes.

## Boundary decision

- Extension type: Module
- Data owner: reading-log
- Cross-module communication: Events only
- Forbidden roots: all other module-owned content roots
