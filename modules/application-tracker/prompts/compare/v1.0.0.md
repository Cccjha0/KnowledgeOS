# 任务

比较一份新的结构化申请研究报告与已有 application-record，
生成 update-result，不直接修改文件。

# 输入

- 当前实例配置；
- 目标 application-record；
- 新 research-report；
- application-tracker 审核政策。

# 判断规则

1. 官方申请系统和官方课程页面优先于第三方来源；
2. 新报告没有变化时，只更新 last_checked、next_check，并追加核验日志；
3. 以下字段属于关键字段：
   - application_status
   - application_open
   - deadline
   - tuition
   - academic_requirement
   - english_requirement
4. 关键字段发生变化时，默认 action=review；
5. 来源冲突时不得覆盖旧值，应生成 review item；
6. 不得根据 checked_at 推断发生变化；
7. 不得联网；
8. 不得编造缺失字段。

# 输出

严格返回符合 schemas/update-result.schema.json 的 JSON。
review_id 使用 REV-YYYY-六位序号的占位格式，由核心平台最终替换。
