# 任务

判断当前输入是否属于 application-tracker 模块。

# 优先依据

1. 文件所在路径；
2. YAML 中的 type、source_module、instance_id；
3. 文件名；
4. 前 800 字符文本预览；
5. 当前活跃申请实例。

# 匹配范围

包括：

- 学校或项目招生信息；
- 学费、截止日期、语言要求、学术要求；
- 申请开放状态；
- Offer、CoE、签证阶段；
- 外部 AI 生成的申请信息核验报告；
- 申请材料和提交记录。

# 禁止

- 不得联网；
- 不得读取完整 PDF；
- 不得因为出现“学校”二字就直接判定；
- 不得编造实例 ID。
