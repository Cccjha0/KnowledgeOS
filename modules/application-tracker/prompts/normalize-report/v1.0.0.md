# 任务

把实例 Inbox 中的一份申请研究材料规范化为 application-tracker Research Report JSON。

# 不变量

1. 只能使用输入文件中明确出现的事实，不得联网，不得补写或猜测数字；
2. 计划、建议和推断不得写成已经发生的事实；
3. 每个 finding 必须引用实际存在于 `sources` 中的 source_id；
4. 不确定或互相矛盾的信息使用 `pending`、`conflicting` 或 `unknown`；
5. 无法确认 Request 时将 `request_id` 设为 null；
6. `checked_at` 必须来自材料中的核验日期，并转换为带时区的 ISO 8601 日期时间；
7. 只返回 JSON 对象，不返回 Markdown、解释或代码块；
8. 不修改输入文件。

# Core 固定字段

Core 会提供并最终覆盖以下字段：

- source_module
- type
- schema_version
- report_id
- research_type
- instance_id
- generation

# 输出

严格返回以下形状，不得增加未列出的顶层字段：

```json
{
  "request_id": null,
  "institution": "非空字符串",
  "program_name": "非空字符串",
  "program_code": "字符串或 null",
  "intake": "非空字符串",
  "checked_at": "带时区的 ISO 8601 日期时间",
  "material_change": false,
  "confidence": 0.0,
  "sources": [
    {
      "source_id": "SRC-001",
      "source_type": "official-application-system | official-course-page | official-handbook | official-fees-page | official-email | official-other | third-party | unknown",
      "title": "字符串",
      "url": "绝对 URL 或 null",
      "accessed_at": "带时区的 ISO 8601 日期时间",
      "notes": "字符串"
    }
  ],
  "findings": {
    "字段名": {
      "value": null,
      "status": "confirmed | pending | conflicting | unknown",
      "confidence": 0.0,
      "source_ids": ["SRC-001"],
      "notes": "字符串"
    }
  },
  "unresolved": ["字符串"],
  "summary": "字符串"
}
```

`sources` 至少包含一项。`confidence` 必须是 0 到 1 的数字。不要输出 Core 固定字段，Core 会补齐它们。
